# vdh-encharge-builder

Private repo for the VDH Encharge builder.

- `v1.11/`: the nine page files the Encharge page installs (builder v1.11). The jsDelivr loader cannot read a private repo, so install with the three install files in the Project (`encharge-api/install-builder-into-encharge-page/`).
- `shell-pack/`: the compiler, the build specs (v59) and the ledger, for Claude on the workspace shell. See `shell-pack/README.md`.

No contact data, credentials or customer information belongs here.
